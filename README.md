## 📖 About This Project

This repository contains the source code for my main developer portfolio. I built this site from scratch to showcase my skills, share my background, and provide a central hub for all the projects I am working on. 

It is designed with a custom dark-themed UI, utilizes modern CSS layouts (Flexbox/Grid), and includes lightweight vanilla JavaScript for interactive elements.

## ✨ Features

* **Modern Dark UI:** A sleek, high-contrast design optimized for readability.
* **Fully Responsive:** Adapts seamlessly to all screen sizes, from mobile phones to ultra-wide desktop monitors.
* **Interactive Navigation:** Mobile-friendly hamburger menu for easy browsing on smaller devices.
* **Scroll Animations:** Subtle IntersectionObserver animations that reveal content smoothly as the user scrolls.
* **Project Showcase:** A dedicated section displaying live projects (like Fitness Pro Ultra) with direct links.

## 🛠️ Tech Stack

* **HTML5:** Semantic structure and accessibility.
* **CSS3:** Custom CSS variables, CSS Grid, Flexbox, and responsive media queries.
* **JavaScript (Vanilla):** DOM manipulation, event listeners, and scroll animations (zero external libraries).
* **Hosting:** GitHub Pages.
